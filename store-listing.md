## Descrição longa

### 🇺🇸 English

```
InstaType is a fast, private text snippet manager for Chrome. Save the
phrases, signatures, addresses and code blocks you type over and over,
then paste them anywhere on the web in two clicks — or with a single
keyboard shortcut.

━━━ How it works ━━━

• Right-click on any input field → InstaType menu → pick a snippet.
• Or focus an input and press the shortcut (default: Alt+Shift+T) to
  open a quick picker with search and arrow-key navigation.
• Or open the side panel to browse, edit and organize your library.

━━━ Smart scopes ━━━

Mark a snippet as Global to make it available everywhere, or scope it
to a single domain. The right-click menu auto-filters to show only
what's relevant for the page you're on — your work signatures don't
clutter your personal email, your code snippets stay on GitHub.

━━━ Works in any input ━━━

• Plain inputs and textareas (forms, search boxes)
• Rich-text editors (Gmail, Notion, Linear, Slack, Discord, Lexical
  and ProseMirror-based apps including WhatsApp Web)
• Multi-line snippets keep their line breaks intact

━━━ Private by design ━━━

Everything is stored locally in your browser using chrome.storage.local.
No accounts. No servers. No analytics. No telemetry. Nothing leaves your
device — not even anonymized.

Your active tab's domain is read in real time (so the menu can filter
by site) but never stored or transmitted.

━━━ Portable ━━━

• Export your library as JSON, anytime.
• Import on another device to restore.
• Filter the export: everything, only globals, or only the current site.

━━━ Multilingual ━━━

UI in English, Portuguese (Brazil) and Spanish. Follows your system
language by default; switch any time from the side panel menu.

━━━ Designed for daily use ━━━

A warm cream interface with serif headlines and monospace text where
it counts. Friendly, calm, fast. Built to disappear when you're not
using it and snap to attention when you are.

━━━ Open & honest ━━━

InstaType is independent software. It will never be ad-supported,
will never require an account, and will never send your data anywhere.
```

## Justificativa de permissões (Single Purpose & Permissions Justification)

Cada permissão precisa ser justificada no formulário da Chrome Web Store.

### Single purpose
**EN:** Save reusable text snippets and insert them into any editable field on the web, via right-click menu, side panel UI, or keyboard shortcut.
**PT:** Salvar trechos de texto reutilizáveis e inserir em qualquer campo editável da web, via menu de contexto, Side Panel ou atalho de teclado.

### Permission: `storage`
Required to persist user-created snippets and language preference across browser sessions. All data stays in `chrome.storage.local` on the user's device.

### Permission: `contextMenus`
Required to add the "InstaType" submenu (with the user's snippets, filtered by current domain) and the "Save selection to InstaType" entry to the browser's right-click menu on editable fields.

### Permission: `sidePanel`
Required to render the main snippet management interface (create, edit, delete, search, filter, import/export) in the Chrome side panel.

### Permission: `activeTab`
Required to read the URL of the currently active tab when the extension is invoked, so that the snippet picker and context menu can filter to snippets scoped to the current site.

### Permission: `tabs`
Required to read the domain of the active tab from the side panel context (where `activeTab` is not sufficient because the panel itself can hold focus), to keep the "This site" filter and the per-domain context menu in sync as the user switches tabs. Only the domain is read — never the full URL, history, or page content.

### Permission: `scripting`
Required as a fallback to inject the content script into tabs that were already open when the extension was installed, so that snippet insertion via the context menu works without requiring the user to reload every existing tab.

### Host permissions (`<all_urls>`)
The content script needs to run on any page where the user might want to insert a snippet (which is potentially any website). It does not read page contents — only writes to the focused editable element when explicitly triggered by user action (context menu click or keyboard shortcut).

### Remote code use
**No.** InstaType bundles all of its JavaScript and assets in the package. The only network requests are to `fonts.googleapis.com` and `fonts.gstatic.com` to load the Instrument Serif, Geist and Geist Mono fonts in the side panel UI. No remote code is executed.
