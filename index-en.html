FAQ

Common questions.

Does InstaType work offline?

Yes. All functionality runs 100% locally in your browser. The only internet requirement is Google Fonts in the Side Panel (cached by Chrome after first load).

Where are my templates stored?

In Chrome's local storage, tied to your browser profile on the device where the extension is installed. If you use the same Chrome profile across machines with sync enabled, data is not automatically synced — use Import & Export for that.

Does it work on every site?

Yes, on any page with editable fields: inputs, textareas and contenteditable divs. Tested on rich-text editors built on the major web frameworks (Lexical, ProseMirror, Slate, Draft.js, Quill).

The shortcut isn't working, what now?

Go to chrome://extensions/shortcuts, find InstaType, and assign the combo manually. Chrome sometimes skips the suggested shortcut when there's a conflict with another extension.

Do templates support variables?

Version 1.0 inserts text exactly as saved. Dynamic variables (like {{name}}, {{date}}, {{clipboard}}) are planned for a future release.

Does it cost anything?

No. Free, no paid tier, no ads. Independent software, no monetization model.
